# 07 — Glossário

Termos usados no curso, com a definição que a narração deve seguir. Ordem alfabética.

| Termo | Definição |
|-------|-----------|
| **ACL (mercado livre)** | Ambiente de Contratação Livre: consumidor escolhe o fornecedor e negocia preço. Hoje, em regra, consumidores de média/alta tensão. |
| **ACR (mercado regulado/cativo)** | Ambiente de Contratação Regulada: consumidor compra da distribuidora pela tarifa homologada pela ANEEL. Onde está o cliente de assinatura. |
| **Alerta operacional** | Aviso da plataforma para falhas e situações que ameaçam faturamento ou operação; único por problema e resolvido sozinho quando a causa some. |
| **ANEEL** | Agência Nacional de Energia Elétrica: regula e fiscaliza o setor. |
| **Assinatura de energia** | Nome comercial da participação de um consumidor em geração compartilhada, com contribuição mensal menor que a economia obtida. Não é venda de energia. |
| **Autoconsumo local / remoto** | Modalidades de GD: créditos usados no próprio local / em outras unidades do mesmo titular, na mesma distribuidora. |
| **Bandeira tarifária** | Acréscimo por kWh definido mensalmente pela ANEEL conforme o custo de geração (verde, amarela, vermelha 1 e 2). |
| **CAC** | Custo de aquisição de cliente: gasto comercial ÷ novos clientes. |
| **Churn** | Percentual de clientes que cancelam no período. |
| **Cobrança (na plataforma)** | Valor que a gestora cobra do cliente: consumo injetado × (1 − desconto) ± ajustes. Status: rascunho, aberta, aguardando pagamento, paga, vencida, cancelada. |
| **Consórcio** | Contrato entre pessoas jurídicas (Lei 6.404, arts. 278–279) usado para reunir empresas na geração compartilhada. |
| **Consumo injetado (plataforma)** | Valor em R$ (e kWh) da energia compensada na fatura do cliente — soma das linhas de compensação (TE, TUSD, bandeira). Base da cobrança. |
| **Cooperativa** | Sociedade de pessoas (Lei 5.764/1971) que aceita PF; usada para geração compartilhada com residências. |
| **Cota** | Quantidade de energia (kWh/mês) destinada a um cliente; vira percentual de rateio. Cota ideal = consumo médio − custo de disponibilidade, com margem de segurança. |
| **Crédito de energia** | kWh injetado pela usina que abate consumo de unidades beneficiárias; válido por 60 meses. |
| **Custo de disponibilidade** | Mínimo faturado no grupo B: 30 kWh (monofásico), 50 (bifásico), 100 (trifásico). |
| **Distribuidora (concessionária)** | Empresa que tem a concessão da rede de distribuição de uma área; mede, rateia créditos e fatura. |
| **Due diligence** | Verificação completa de uma usina antes de fechar contrato (5 blocos no curso). |
| **EMUC** | Empreendimento com múltiplas unidades consumidoras (condomínios). |
| **Energia disponível / alocada / saldo** | Na plataforma: o que a usina pode distribuir / o que está vinculado a clientes / a diferença ainda vendável. |
| **Energia injetada** | Energia que a usina entrega à rede, medida pelo medidor bidirecional; gera créditos. |
| **Fio A** | Parcela da TUSD que remunera a transmissão. |
| **Fio B** | Parcela da TUSD que remunera a rede de distribuição; na GD II, uma parte crescente não é compensada (60% em 2026, 75% em 2027, 90% em 2028). |
| **GD I / GD II / GD III** | Enquadramentos da Lei 14.300: regra antiga até 2045 / transição do Fio B / usinas > 500 kW concentradas (Fio B integral + parte do Fio A). |
| **Geração compartilhada** | Modalidade em que consumidores diferentes, reunidos em consórcio, cooperativa, condomínio ou associação, recebem créditos de uma usina na mesma distribuidora. Base da assinatura. |
| **Gestora** | A empresa do aluno: capta clientes e usinas, opera faturamento e cobrança e é remunerada pela taxa de administração. |
| **Grupo A / Grupo B** | Média/alta tensão (≥ 2,3 kV; demanda + energia) / baixa tensão (só energia). Grupo B é o público principal. |
| **ICP** | Perfil de cliente ideal. |
| **kW / kWh / kWp** | Potência / energia (o que se paga e o que a usina entrega) / potência-pico dos painéis (tamanho da usina). |
| **Lei 14.300/2022** | Marco legal da micro e minigeração distribuída. |
| **Lista de rateio** | Cadastro, na distribuidora, das unidades beneficiárias e do percentual de créditos de cada uma. |
| **Margem de contribuição** | Taxa de administração menos custos variáveis (meio de pagamento, inadimplência, impostos); paga os custos fixos. |
| **Micro / minigeração** | Até 75 kW / acima de 75 kW até 5 MW (despacháveis) ou 3 MW (não despacháveis, como solar, nas regras atuais). |
| **O&M** | Operação e manutenção da usina (limpeza, inspeção, reparos). |
| **Ocupação** | Energia alocada ÷ energia disponível; meta 90–98%. |
| **Parecer de acesso** | Documento da distribuidora que aprova a conexão de uma usina e suas condições. |
| **Pendência (fatura)** | Problema detectado automaticamente na fatura (sem UC, duplicada, valor inválido, sem desconto ativo etc.). |
| **Ponto de equilíbrio** | Volume (kWh/mês) em que a margem de contribuição cobre os custos fixos. |
| **Produtor** | Dono da usina; recebe o repasse (aluguel) pela usina locada à entidade. |
| **Produtividade** | kWh gerados por kWp por mês numa região (no Brasil, ~100–140). |
| **Régua de cobrança** | Sequência padronizada de contatos antes e depois do vencimento. |
| **Repasse** | Valor pago ao produtor: crédito − desconto do cliente − taxa de administração (por kWh). |
| **SIN / ONS / CCEE** | Sistema Interligado Nacional / seu operador / câmara que contabiliza o mercado de energia. |
| **SOP** | Procedimento operacional padrão: a rotina diária, semanal e mensal escrita. |
| **SPE** | Sociedade de propósito específico, usada para isolar uma usina (risco e financiamento). |
| **Taxa de administração** | Remuneração da gestora, em % do valor do crédito (padrão do curso: 15%). |
| **TE / TUSD** | Tarifa de Energia / Tarifa de Uso do Sistema de Distribuição (Fio A, Fio B, encargos, perdas). |
| **UC (unidade consumidora)** | Instalação identificada pelo número na conta de luz; código + distribuidora é único na plataforma. |
| **Valor do crédito** | Quanto vale, para o cliente, 1 kWh compensado: tarifa menos a parcela não compensada do Fio B (e efeito dos tributos). Na plataforma: "Tarifa GD2" da concessionária. |
